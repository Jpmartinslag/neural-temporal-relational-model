# Dashboards

Presentable HTML dashboards, generated offline from processed data and frozen results.
None of them run a live server or fetch data at view time — each is a static export
regenerated by its own build script when the underlying data changes.

## France ZE2020 MVP — current

```text
fr_ze2020_dashboard_mvp.html
```

Generated by `src/data/france_ze2020/build_fr_ze2020_dashboard_mvp.py`. This is the
current, standalone dashboard for the France/ZE2020 canonical benchmark: a map
(geometry verified 280/280 zones), a forecast panel restricted to control baselines
(persistence/Ridge), a descriptive sectoral view, and an exploratory relational
graph. No recommendation, no causal claim, and no fabricated predicted series if the
predictions file is absent. The document that originally specified it,
`HERALD_22_FR_ZE2020_DASHBOARD_MVP.md`, was archived externally with a checksum as
part of this delivery's `reports/canonical/` consolidation and is recoverable from
`_delivery_cleanup_archive/2026-08-24/reports/canonical/` or from git history.

The same build script also reads `herald_france_final_dashboard.html` (below) as an
input for one of its comparison panels — that file is a dependency, not a leftover.

## European panel — observatory dashboards

Four dashboards document the exploratory NL/BE/PT/FR European-panel extension
described in [`src/data/european_panel/README.md`](../../src/data/european_panel/README.md).
Each is generated by its own script under `src/data/european_panel/`:

| File | Generator |
|---|---|
| `herald_observatory_v03_dashboard.html` | `build_observatory_v03.py` |
| `herald_observatory_v04_granular_dashboard.html` | `build_observatory_v04_dashboard.py` |
| `herald_observatory_v05_narrative_dashboard.html` | `build_observatory_v05_narrative_dashboard.py` |
| `herald_observatory_v051_narrative_dashboard.html` | `build_observatory_v051_narrative_dashboard.py` |

The four are successive iterations (v03 → v04 → v05 → v051), not four independent
views; v051 is the most recent. Earlier versions are kept for traceability rather
than deleted. As with the panel itself, nothing here should be read as evidence that
the model generalizes across countries — see the European panel README's target-
comparability notes.

## Naming note

Filenames in this folder keep the legacy `herald_*` prefix from when they were
written. That is a filename, not a claim about the model's current public name — see
`docs/EXPERIMENT_PROVENANCE.md` §1 for the naming map.
