## Status vocabulary used in this matrix

- **ACTIVE** — currently validated and citable within its stated scope.
- **PARTIAL** — some sub-result validated, some not; never cite the unvalidated part as final.
- **CLOSED_FAIL** — tested under a pre-registered gate and rejected; Charter §8 governs reopening.
- **HISTORICAL** — superseded by a later phase in the same line of work (not used as a standalone row above; see canonical #1 for the full historical lineage).
- **PLANNED** — not started; no implementation exists.
